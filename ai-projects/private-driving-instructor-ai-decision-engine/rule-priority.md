# Rule Priority Hierarchy

1. **Sensitive-case escalation** — overrides normal package rules when human judgment is required.
2. **Missing required information** — obtain required information before continuing.
3. **Unverified required information** — complete approved verification before dependent decisions.
4. **Approved decision rule** — recommend the pathway defined by the matching rule.
5. **No matching approved rule** — route to human review.

## Key concept
Rule precedence determines which rule controls when multiple rules appear to match.
